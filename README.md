# Tarafdar Telecom

বাংলায় একক ব্যবহারকারীর দোকান পরিচালনা। বর্তমান Sites সংস্করণের ভিত্তিতে তৈরি। পণ্য ও সার্ভিস, স্টক, কাস্টম বিল, বাকি, কাস্টমার খাতা, Cash/COD/UPI রেকর্ড ও A4 রসিদ অন্তর্ভুক্ত। UPI নির্বাচন করলে বিলের পেমেন্ট পদ্ধতি লেখা থাকে। টাকা কাটার গেটওয়ে এই সংস্করণে নেই।

## Windows-এ চালান

1. ZIP-টি Extract All করুন। কম্পিউটারে Python 3 থাকলে আলাদা প্যাকেজ ইনস্টল করতে হবে না। প্রয়োজন হলে [Python for Windows](https://www.python.org/downloads/windows/) থেকে নিন।
2. Start-Windows.cmd ডাবল-ক্লিক করুন। ব্রাউজার নিজে না খুললে http://127.0.0.1:8765/ খুলুন। ব্যবহারের সময় কমান্ড উইন্ডো খোলা রাখুন। বন্ধ করতে Ctrl+C চাপুন।
3. সেটিংসে দোকানের যোগাযোগের তথ্য ও লোগো দিন। পণ্য ও সার্ভিস থেকে আইটেম যোগ করুন। স্টকবিহীন সার্ভিসের স্টক ঘর খালি রাখুন।
4. নতুন বিল থেকে আইটেম, কাস্টমারের তথ্য ও পরিশোধিত টাকা লিখুন। ইনভয়েস তৈরি করে A4 প্রিন্ট / PDF চাপুন।

macOS বা Linux-এ এই ফোল্ডার থেকে `python3 start.py` চালান। সার্ভার শুধু এই কম্পিউটারের লুপব্যাক ঠিকানায় খোলে। একই কম্পিউটার ও ব্রাউজার প্রোফাইলে যাঁর প্রবেশাধিকার আছে, তিনি খাতা খুলতে পারেন।

## GitHub-এ ব্যক্তিগত রিপোজিটরি

ল্যাপটপে Git ও GitHub CLI ইনস্টল করুন। ZIP-এর ভেতরে যে ফোল্ডারে এই README আছে সেটি VS Code-এ খুলে Terminal চালু করুন।

```sh
gh auth login
gh auth setup-git
git init -b main
git add .
git commit -m "Add Tarafdar Telecom shop manager"
gh repo create tarafdar-telecom --private --source=. --remote=origin --push
```

প্রথম commit-এ Git পরিচয় চাইলে ওই ফোল্ডারে `git config user.name "YOUR NAME"` এবং `git config user.email "YOUR GITHUB EMAIL"` চালিয়ে নিজের তথ্য দিন। তারপর commit থেকে আবার চালান। রিপোজিটরির নাম আগে থেকেই থাকলে নতুন রিপোজিটরির জন্য অন্য নাম বেছে নিন।

পরবর্তী কোড পরিবর্তন পাঠাতে নিচের কমান্ড ব্যবহার করুন।

```sh
git status
git add -u
git commit -m "Update shop manager"
git push
```

নতুন সোর্স ফাইল তৈরি করলে commit-এর আগে আলাদা করে `git add filename` চালান। Actions-এর Check shop source ওয়ার্কফ্লো কোডের সিনট্যাক্স ও প্রয়োজনীয় ফাইল পরীক্ষা করে। GitHub-এ push করলে বর্তমান Sites সাইটটি স্বয়ংক্রিয়ভাবে আপডেট হয় না।

## পুরোনো হিসাব আনা

বর্তমান Sites সাইটে যে ব্রাউজারে হিসাব আছে সেখান থেকে সেটিংস → ব্যাকআপ ডাউনলোড করুন। ল্যাপটপের নতুন লোকাল সাইটে সেটিংস → ব্যাকআপ ফেরান থেকে JSON বাছুন। ফেরালে সেই ব্রাউজারের বর্তমান খাতা বদলে যাবে। প্রয়োজন হলে আগে তারও ব্যাকআপ নিন।

ডেটা IndexedDB-তে থাকে। প্রতিদিন একই ব্রাউজার প্রোফাইল ও একই ঠিকানা ব্যবহার করুন। সাইট ডেটা মোছার আগে ব্যাকআপ নিন। কাস্টমারের ব্যাকআপ ও রসিদ ব্যক্তিগত জায়গায় রাখুন। রিপোজিটরিতে কেবল কোড রাখুন। অনলাইনে ব্যক্তিগত প্রবেশের জন্য আগের owner-only Sites লিংক ব্যবহার করুন। এই স্বতন্ত্র সোর্সে অনলাইন লগইন যুক্ত নেই।
